A "yes" means that version exposes the interface in [`@standard-schema/spec@1.1.0`](https://github.com/standard-schema/standard-schema/blob/v1.1.0/packages/spec/src/index.ts). Standard Schema is `~standard.validate`. Standard JSON Schema is `~standard.jsonSchema.input` and `output`. A JSON Schema helper under another name is listed in the target column and is not counted as Standard JSON Schema.

There is no runtime-speed column. No new benchmarks were run. The tskm bundle figures are copied from [`bench/json-schema-static.md`](../bench/json-schema-static.md) at [`c96c3b9`](https://github.com/ushironoko/tskm/blob/c96c3b9a2ec219d65ca3b35c10653e082ed99898/bench/json-schema-static.md).

| entry | minify bytes | gzip bytes | contains `convert.ts` |
| --- | ---: | ---: | --- |
| source static | 4998 | 2012 | no |
| source runtime | 14241 | 4724 | yes |
| dist static | 5047 | 2046 | no |
| dist runtime | 14249 | 4762 | yes |

Source gzip delta (runtime − static): 2712 bytes. The static bundle does not contain `src/json-schema/convert.ts`.
